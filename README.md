# Snipit for Raycast

Share code snippets securely with [snipit.sh](https://snipit.sh) directly from Raycast.

## Features

- **Create Snippet** - Share text or code with one command
- **Paste Snippet** - Fetch and paste snippets from URL
- **History** - Access your recently created snippets

### Security Options
- 🔒 Password protection (AES-256 encryption)
- ⏰ Auto-expiration (1h to 2 weeks)
- 🔥 Burn after read

## Installation

1. Open Raycast
2. Search for "Snipit" in the Store
3. Install

## Usage

### Create Snippet
1. Copy code to clipboard
2. Open Raycast → "Create Snippet"
3. Configure options (language, expiry, password)
4. Submit → URL is copied to clipboard

### Paste Snippet
1. Open Raycast → "Paste Snippet"
2. Enter snipit.sh URL
3. Submit → Content is pasted
